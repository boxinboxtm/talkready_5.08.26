# HANDOFF — TalkReady (для продолжения в Claude Code)

Вставь этот файл (или его содержание) в начало новой сессии в Code-табе, чтобы дать контекст.

## Что это
Голосовой тренажёр английского для нетворкинга. Собеседника играет Claude через Anthropic API.
Собран строго по ТЗ v.02 (`docs/` не входит в репо — ТЗ у продукта). Формат: Vite + React, один компонент, тонкий серверный прокси для ключа.

## Стек
- Фронт: Vite + React 18, один компонент `src/TalkReady.jsx`, inline-стили (без Tailwind).
- Прокси: `lib/anthropic.js` (общий вызов Anthropic, ключ на сервере) →
  - прод: `api/chat.js` (Vercel serverless),
  - локально: `server.js` (Express на :3001, Vite форвардит `/api`).
- Память между сессиями: `localStorage` (`talkready:last`).
- Модель зашита на сервере: `claude-sonnet-5` (браузер не выбирает модель).

## Как запустить
```bash
npm install
cp .env.example .env      # вписать ANTHROPIC_API_KEY
npm run dev               # http://localhost:5173
```

## Статус (проверено)
- Прокси (`lib/anthropic.js`) протестирован живьём: без ключа → 500 с внятным сообщением; с неверным ключом → реальный 401 от Anthropic (значит эндпоинт/заголовки/тело верные). С валидным ключом вернёт `content`.
- `src/TalkReady.jsx` и `src/main.jsx` компилируются (esbuild), все серверные модули проходят `node --check`.
- НЕ проверено в этой среде: полный `vite build` (не встал из-за размера бинарников esbuild в песочнице) — на локальной машине встаёт штатно.

## Что реализовано по ТЗ
- Диалог с ИИ-персоной, 4 сценария + случайный; системный промпт держит все запреты блока 2.
- Метрики: Task Completion, Speech Latency (>4с), Elaboration (<7 слов), Clarification (+антигейминг).
- Мини-цели, фраза-опора при застревании (>10с), холистический гейт, режим «печатать вместо говорить».
- Экран «Мои успехи»: 4 шкалы + сравнение с прошлой сессией, разбор (сильная сторона → зона роста → микропрактика), развлекательный пункт, печать в PDF.
- Палитра сенота, «рост, а не оценка», жёлтый только на успех/главное действие.

## Что дальше (бэклог)
1. **Проверить голос на реальном телефоне (https)** — Web Speech API требует https или localhost; на деплое проверить STT/TTS вживую.
2. **Согласие и приватность (блок 8)** — сейчас чекбокс-заглушка. Нужны: реальный срок хранения транскриптов, формулировка согласия, удаление данных. Решение продукта/юристов.
3. **STT-движок** — сейчас браузерный Web Speech (нестабилен, только Chrome/Edge). ТЗ хочет устойчивость к акценту B1–B2 и шуму → рассмотреть серверный STT (напр. Whisper) как отдельный эндпоинт.
4. **PDF** — сейчас через `window.print()`. Если нужен «настоящий» серверный PDF с брендом — генерить на бэке.
5. **Хранение истории** — `localStorage` только на одном устройстве. Для кросс-девайса нужен бэкенд + аккаунты.
6. **Системный промпт собеседника** вынести в редактируемый конфиг (сейчас в `partnerSystem()` внутри компонента).
