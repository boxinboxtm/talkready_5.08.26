# HANDOFF — TalkReady, первый прототип

Контекст для продолжения работы. Вставь этот файл в начало новой сессии.

## Что это

Голосовой тренажёр английского для нетворкинга, собранный по **ТЗ v.02** — версии
«golden ТЗ + границы первого прототипа». Само ТЗ в репозиторий не входит: оно у продукта.

**Прототип работает полностью офлайн:** без API-ключей, без интернета, без платных сервисов.
Голос и распознавание — браузерные (Web Speech API), собеседницу играет сценарный движок.

## Главное архитектурное решение

Собеседник абстрагирован за интерфейсом из двух функций — `askPartner` и `askFeedback`.
Реализаций две, переключаются одной строкой в `src/config/engine.js`:

- `"local"` — сценарий в браузере. Работает сейчас, ничего не требует.
- `"claude"` — языковая модель через свой серверный прокси. Код готов, нужен ключ.

Приложение импортирует только `src/lib/engine.js` и не знает, кто за ним стоит.
Подключение реальной модели — это правка одной строки плюс `.env`, а не переписывание.

Второе решение: **весь контент лежит в `src/config/`** — сценарий, реплики, подсказки,
формулировки разбора. Прямое требование блока 1 ТЗ. Методист правит их без программиста.

## Как устроен офлайн-собеседник

Не линейный сценарий, а маленький диалоговый менеджер (`src/lib/partner.local.js`).
Первая версия была линейной, и её сразу забраковали на тесте: Maya выдавала следующую
заготовку независимо от сказанного — спрашивала «what do you do?» после того, как ей
уже рассказали про работу. Ощущалось как разговор невпопад.

Сейчас на каждом шаге движок:
1. разбирает реплику — вопрос? тема? имя? односложно? не понял? русский? прощание?
2. реагирует на содержание — отвечает на вопрос или подхватывает тему/сферу работы;
3. выбирает следующий **ход** из `MOVES`, пропуская те, чью тему человек закрыл сам.

Состояние разговора: имя человека, множество закрытых тем, использованные ходы,
последний ход (нужен для переспроса). Сбрасывается через `resetPartner()`.

Что это дало: имя запоминается и звучит в прощании; закрытая тема не всплывает;
неизвестный вопрос получает честное «не знаю» вместо игнорирования; односложный ответ
вызывает переспрос другими словами, а не переход к следующей теме.

**Потолок остаётся.** Это правила, а не понимание. Maya не поймёт шутку, не удержит
длинную мысль и не среагирует на то, чего нет в `TOPICS` и `ANSWERS`. Снимается
переключением `ENGINE` на `"claude"` — ради этого движки и разведены за одним интерфейсом.

## Важно про историю репозитория

Первый коммит содержал **другой, более широкий прототип** — четыре сценария, метрики,
экран «Мои успехи», PDF, режим печати. Он собирался под раннюю редакцию ТЗ, **до того**
как в v.02 появился блок 0 с границами. Текущая версия переписана под эти границы.
Если понадобится тот код — он в истории git, первый коммит.

## Стек

- Vite + React 18, обычный CSS (`src/styles.css`), без Tailwind.
- Голос: Web Speech API — `speechSynthesis` и `SpeechRecognition`.
- Состояние между сессиями не хранится: по ТЗ (блок 0) этого в прототипе нет.

## Как запустить

```bash
npm install
npm run dev        # http://localhost:5173
```

Для режима `"claude"`: создать `.env` с `ANTHROPIC_API_KEY`, переключить `ENGINE`
и запускать `npm run dev:claude`. Подробности — в `README.md`.

## Статус проверки

**Проверено на этой машине (Chrome, эмуляция 375×812, микрофон и синтез — заглушки):**
- `npm run build` проходит, 40 модулей.
- Полный разговор от начала до конца: 7 реплик Maya, 6 ответов, естественное прощание.
- Переспрос («Sorry, could you say that again?») → Maya повторяет мысль **проще**
  и сценарий **не** едет дальше. Это работает.
- Экран разбора: три части, каждая цитирует реальную фразу пользователя.
- «Попробовать ещё раз» сбрасывает сценарий на первую реплику.
- Ошибка «не удалось распознать» — формулировка дословно по ТЗ, разговор **не** продолжается сам.
- Ошибка «нет доступа к микрофону» — сообщение, инструкция и «Повторить».
- Обе подсказки: опора подбирается под текущий этап, фраза уточнения — из банка.
- Движок отдельно прогнан на пяти диалогах (сильный / односложный / с переспросами /
  с русским / молчание) — сценарий `scratchpad`, в репозиторий не входит.

**НЕ проверено:**
- **Реальный микрофон и реальный синтез речи.** Всё голосовое тестировалось заглушками.
- **Живой Chrome на Android** — критерии приёмки из блока 11 ТЗ проверяются только там.
- Режим `"claude"` — не запускался ни разу, ключа не было.

## Что дальше (бэклог)

1. **Прогнать на настоящем телефоне** по одиннадцати критериям блока 11 ТЗ. Нужен https —
   туннель или деплой. Это первое.
2. **Вычитать банк подсказок** — `HINTS_STATUS = "draft"`, нужна проверка преподавателем.
3. **Проверить качество голоса** — браузерный синтез звучит роботизированно; если мешает
   ощущению «безопасной репетиции» из блока 7, думать про внешний TTS.
4. **Подключить `"claude"`**, когда дойдёт очередь до ключей: заготовленные реплики
   сменятся на генерацию, ограничение из README раздел 2 снимется.
5. **Вернуть режим «печатать вместо говорить»** — ТЗ (блок 0) просит сразу после рабочего
   цикла: контекст «метро, без наушников» из блока 4.
6. Дальше по блоку 0: сценарии, история сессий, метрики, отчёт, прогресс.
