# TalkReady — первый прототип

Голосовой тренажёр английского для нетворкинга. Собран по **ТЗ v.02**, строго в границах
блока 0 («Границы первого работающего прототипа»).

Прототип проверяет один полный цикл:

> пользователь слышит реплику собеседника → отвечает голосом → приложение распознаёт ответ →
> собеседник продолжает разговор → после завершения пользователь получает короткую обратную связь.

**Работает без интернета, без API-ключей и без платных сервисов.**

---

## 1. Запуск

Нужен **Node 18+**.

```bash
npm install
```

```bash
npm run dev
```

Откроется на **http://localhost:5173**. Больше ничего настраивать не нужно.

> **Микрофон работает только на `https` или на `localhost`.** Это ограничение браузера.
> Целевая среда по ТЗ — **Chrome на Android**. В Safari и Firefox распознавание речи не работает;
> приложение честно скажет об этом, а не будет молча не реагировать.

### Как открыть на телефоне

По локальному адресу вида `http://192.168.x.x` браузер микрофон не даст — нужен https. Варианты:

```bash
npx localtunnel --port 5173
```

либо задеплоить статику куда угодно (Netlify, Vercel, GitHub Pages) — в демо-режиме
серверная часть не нужна вообще, хватит папки `dist/` после `npm run build`.

## 2. Два движка собеседника

Кто именно играет Maya, решает **одна строка** в `src/config/engine.js`:

```js
export const ENGINE = "local";   // или "claude"
```

| | `"local"` — сейчас | `"claude"` — позже |
|---|---|---|
| Кто отвечает | сценарий в браузере | языковая модель |
| Нужен ключ | нет | да, `ANTHROPIC_API_KEY` |
| Нужен интернет | нет | да |
| Реплики | собраны заранее, подбираются по ответу | генерируются на ходу |
| Запуск | `npm run dev` | `npm run dev:claude` + `.env` |

Оба движка отдают одинаковый интерфейс (`askPartner` / `askFeedback`), поэтому переключение
не трогает ни один другой файл. Код для Claude уже написан и лежит в `src/lib/api.js`,
серверный прокси — в `lib/anthropic.js`, `api/chat.js` и `server.js`.

**Честное ограничение.** ТЗ (блок 1) требует, чтобы собеседник *генерировал* реплики.
Локальный движок этого не умеет — он подбирает заготовленные. Живость держится на трёх слоях:
прямой вопрос получает прямой ответ, сфера работы подхватывается конкретной реакцией,
а на «не понял» та же мысль повторяется проще. Это осознанный компромисс демо-режима,
а не недоделка.

## 3. Структура

```
talkready/
├── src/
│   ├── App.jsx                    # экраны и цикл разговора (ТЗ, блок 9)
│   ├── styles.css                 # палитра «сенот», Manrope, mobile-first (блоки 6–7)
│   ├── config/                    # ⭐ ВЕСЬ КОНТЕНТ — правится без программиста
│   │   ├── engine.js              #    переключатель local / claude
│   │   ├── scenario.js            #    сценарий, мини-цели, системный промпт v1
│   │   ├── partner-script.js      #    реплики Maya для офлайн-режима
│   │   ├── hints.js               #    банк подсказок (статус draft)
│   │   └── feedback-rules.js      #    формулировки обратной связи
│   └── lib/
│       ├── engine.js              # выбирает движок
│       ├── partner.local.js       # офлайн-собеседник и разбор диалога
│       ├── api.js                 # тот же интерфейс, но через Claude
│       └── speech.js              # браузерные распознавание и озвучка
├── lib/anthropic.js               # серверный вызов Anthropic (для режима claude)
├── api/chat.js                    # Vercel-функция POST /api/chat
└── server.js                      # локальный dev-прокси
```

⭐ `src/config/` — здесь лежит всё, что решает продукт и методист.
Чтобы поменять поведение собеседника или тон разбора, `App.jsx` трогать не нужно.

## 4. Что входит в прототип

| Требование ТЗ | Где |
|---|---|
| Один сценарий: первое знакомство на networking event | `config/scenario.js` |
| Один вымышленный собеседник (Maya Ortega) | `config/scenario.js` |
| 6–8 реплик собеседника, затем завершение | `SCENARIO.aiTurns` |
| Голос собеседника + дублирование текстом | `lib/speech.js` |
| Запись и распознавание ответа | `lib/speech.js` |
| Кнопка «Мне нужна подсказка», два типа подсказок | `config/hints.js` |
| Английский только; мягкий возврат с русского | `partner-script.js`, `scenario.js` |
| Обратная связь из трёх частей | `config/feedback-rules.js` |
| «Попробовать ещё раз» | `App.jsx` |
| Три сценария сбоя: не расслышал / нет микрофона / ошибка сервиса | `App.jsx` |

Блок 0 выносит это в следующие версии; список — решение, а не недоделка:

проверка произношения · хранение транскриптов · согласие и сроки хранения данных.

## 6. Открытые вопросы

- **Банк подсказок — `draft`.** `HINTS_STATUS` в `config/hints.js`: фразы собраны для проверки
  цикла и требуют вычитки преподавателем английского.
- **Реплики Maya заготовлены**, а не сгенерированы — см. раздел 2. Снимается переключением на `"claude"`.
- **STT браузерный.** По ТЗ для прототипа этого достаточно; устойчивость к акценту и шуму —
  задача следующей версии.
